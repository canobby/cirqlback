## 🛠 Troubleshooting

### Common Customer Issues

#### Cirql Tag Not Working
**Problem**: Phone doesn't respond when tapping the tag
**Solutions**:
1. Ensure NFC is enabled in phone settings
2. Try different areas of the tag surface
3. Remove phone case if it's thick or metallic
4. Hold phone flat against the tag for 2-3 seconds
5. Try manually visiting the business's Cirql page through the map

#### Map Not Showing Businesses
**Problem**: Discovery map appears empty or incomplete
**Solutions**:
1. Check location permissions in browser settings
2. Refresh the page and allow location access
3. Try searching for specific business names
4. Check if you're in an area with Cirql-enabled businesses
5. Contact support if businesses you know are participating don't appear

#### Rewards Not Appearing
**Problem**: Tapped tag but didn't receive expected reward
**Solutions**:
1. Check if the campaign is still active (some have expiration dates)
2. Verify you meet campaign requirements (first-time customer, minimum purchase, etc.)
3. Check your browser's popup settings
4. Clear browser cache and try again
5. Contact the business directly if the issue persists

### Common Business Issues

#### Low Tag Engagement
**Problem**: Few customers are tapping your Cirql tags
**Solutions**:
1. **Improve tag placement**: Place tags where customers naturally interact (near register, menu, entrance)
2. **Add signage**: Create small signs explaining what Cirql tags are and their benefits
3. **Staff training**: Ensure staff can explain Cirql tags to customers
4. **Campaign optimization**: Review if your offers are compelling enough
5. **Cross-promotion**: Partner with other businesses for shared campaigns

#### Website Not Updating
**Problem**: Changes to business website aren't appearing
**Solutions**:
1. Clear browser cache and refresh
2. Check if changes were saved properly in the website builder
3. Allow 5-10 minutes for changes to propagate
4. Try viewing in an incognito/private browser window
5. Contact support if issues persist beyond 24 hours

#### Analytics Discrepancies
**Problem**: Analytics numbers don't match expectations
**Solutions**:
1. **Check date ranges**: Ensure you're viewing the correct time period
2. **Understand metrics**: Review what each metric actually measures
3. **Account for delays**: Some analytics update with a 2-4 hour delay
4. **Compare with other sources**: Cross-reference with your POS system or other tracking
5. **Contact support**: Provide specific examples of discrepancies
