# Cirqlback User Manuals

Welcome to Cirqlback — the tap‑to‑earn loyalty and local‑discovery platform. Customers tap an NFC "Cirql" tag with their phone to earn rewards; businesses run campaigns; coordinators manage regions; admins run the platform.

Pick the guide for your role:

| Guide | Who it's for |
|---|---|
| [Customer Guide](./customer-guide.md) | Anyone who taps a Cirql tag to earn rewards. No account or app required. |
| [Business Guide — Basic (Core plan)](./business-basic-guide.md) | Single‑location businesses on the **Core $19.99/mo** plan (or the free Starter trial). |
| [Business Guide — Pro plan](./business-pro-guide.md) | Growing / multi‑location businesses on the **Pro $49.99/mo** plan. |
| [Coordinator Guide](./coordinator-guide.md) | Community Coordinators who manage a city/region and earn a revenue share. |
| [Admin Guide](./admin-guide.md) | Platform administrators. |

**The web address:** your Cirqlback site (locally, `http://127.0.0.1:5000`). Log in at **`/auth`**.

**A note on plans:** *Starter* is a free 6‑month trial, *Core* ("Basic") is $19.99/mo, and *Pro* is $49.99/mo. Optional add‑ons (Advanced Analytics, Custom Branding, Map Priority, Contest/Scavenger‑Hunt Builder) can be purchased by any paid business. Customers are always free.
